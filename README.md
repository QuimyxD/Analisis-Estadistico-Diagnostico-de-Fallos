# Analisis-Estadistico-y-Diagnostico-de-Fallos
Procesar un conjunto de señales de un motor de inducción que opera en diferentes condiciones (un estado sano y tres estados de falla). Calcular métricas estadísticas clave utilizando la librería de funciones propia desarrollada previamente en el curso y visualizar las distribuciones para realizar comparaciones diagnósticas.
